## 1. 仓库结构总览

读之前先记下每个顶层目录是干什么的：

| 目录 | 作用 |
|---|---|
| `ggml/` | 张量库（数据结构 + 各后端 kernel） |
| `src/` | llama.cpp 核心：模型加载、图构建、采样 |
| `common/` | 命令行工具共用的辅助代码 |
| `examples/` | 各种示例程序（cli、server、bench…） |
| `convert_hf_to_gguf.py` | 把 HuggingFace 权重转成 GGUF |
| `gguf-py/` | GGUF 文件格式的 Python 实现 |
